# Справку не видно на сайте

Статьи `help/` доезжают до API (`publish-help.yml`, индекс в памяти —
`specs/help.md`, 6), но человеку на сайте их не показать: ни страницы «Помощь», ни поиска
по справке в клиенте нет. Читать её будет только ассистент — инструмент `search_help`
(`specs/help.md`).

## Почему не сейчас

- **Бюджет initial.** 409.31 КБ при ошибке 410 (`bundle.md`): в оболочку справке места нет —
  ни ссылки с иконкой в шапке, ни словаря. Только ленивым маршрутом.
- **Нечего показывать человеку, кроме того, что ответит ассистент.** Пока ассистента нет,
  страница справки — единственный читатель статей; с ассистентом она станет вторым.

## Как сделать, когда понадобится

Два пути, оба без веса в initial:

1. **Ленивый маршрут `/help`** в клиенте: свой чанк и словарь, статьи берёт из API
   (`GET api/Help/Article?name=`, `GET api/Help/Search?q=` поверх `HelpSearch`). Плюс —
   поиск тот же, что у ассистента; минус — новый контроллер без прав (справка общая)
   и разметка Markdown в чанке (`ngx-markdown` или свой разбор: формат узкий, разделы `##`,
   списки, жирный).
2. **Статический сайт** из `help/` той же публикацией: `publish-help.yml` дополнительно
   собирает HTML в `~/pettemplate-help/current/site` и nginx отдаёт его по `example.com/help/`
   (`location /help/` в `IaC/nginx/conf/nginx.conf`, проверка `nginx -t`). Клиент ничего
   не грузит — в шапку идёт только ссылка, без поиска.

Поле `page` у статьи уже есть — переход из справки в приложение одной ссылкой.
