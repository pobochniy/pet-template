# Секрет VK-приложения в истории git

В `AuthController` раньше лежал закомментированный `VkOAuthCallback`
с `GetVkUserToken`: в нём открытым текстом `client_id` и `client_secret` VK-приложения
и адрес `wisdomsnakes.ru` — остаток проекта, из которого вырос шаблон. Код удалён,
но строка осталась в истории git — и попадёт к каждому, кто клонирует шаблон.

Что сделать (владелец):

1. Перевыпустить защищённый ключ того VK-приложения в кабинете VK — старый считать
   скомпрометированным. Переписывать историю ради этого не нужно: после смены ключа
   строка в ней ничего не открывает.
2. Секреты внешних входов приходят только из настроек (`VkOptions`, секреты GitHub),
   в коде их нет — правило уже в `specs/infrastructure.md` («Секретов в репозитории нет»).

Файл удаляется вместе со строкой, когда ключ перевыпущен.
