# Видимость полей профиля: скрыто, коллегам, всем

Решение владельца (ASU, 2026-10-29), шаблон его наследует: чужие профили открывать можно,
но каждое поле профиля показывается по своей настройке. Пока не делаем — в шаблоне карточки
чужого профиля нет вовсе, а список пользователей разбирается в `profile-contacts.md`.

## Три уровня

| Уровень | Кому видно | Пример |
|---|---|---|
| Скрыто | Никому. Поле только для технических действий — вход, восстановление пароля, письма | почта, телефон по умолчанию |
| Коллегам | Тем, у кого с владельцем есть хотя бы один общий workspace (действующее членство у обоих) | комментарий |
| Всем | Любому вошедшему | логин |

Логин и `id` видны всегда: без них не работают список участников и `user-name`.
Значение по умолчанию у контактов — «скрыто»: включённая видимость — решение человека,
а не наше.

## Что сделать

- **Модель.** По полю видимости на каждое показываемое поле профиля (`Email`, `PhoneNumber`,
  `Comment` и что добавится) — перечисление `Hidden = 0, Colleagues = 1, Everyone = 2`, int
  в базе, значения только в конец. Порядок — порядок открытости, как `VisibilityEnum` в Lad.
  Миграцию пишет владелец.
- **Сервер.** `GET api/Profile/View?userId=` (как в Lad) отдаёт `ProfileViewDto` — поля,
  собранные по видимости и по тому, есть ли у смотрящего и владельца общий workspace.
  Отдельно от `Account/Logins`: тот — про себя. Скрытое не уходит наружу никогда, в том
  числе в `Workspace/GetMembers`. Тест — что скрытое поле не попадает ни в один ответ
  про чужой профиль.
- **Клиент.** Карточка `/profiles/user/<id>` — на `Profile/View`. В «Основном» своего
  профиля — переключатель видимости у каждого поля. Тексты — через словари.
- **Админка** видит всё: «Аккаунты» — поддержка, не соседи (`specs/admin.md`, 12).

## Образец

`Lad/tech-debt/profile-contacts.md`, раздел «Чего не хватает ещё — самой видимости»: флаги
видимости в профиле («всем, своим пространствам, никому») и `ProfileViewDto` по ним, а не
фиксированным списком полей. В Lad тоже не сделано — переносить нечего, кроме экрана
`Profile/View` и проверки `View_DoesNotLeakContactsWalletOrPlace` (в шаблоне — без кошелька
и места). Шкала — `Lad.Shared/Enums/VisibilityEnum.cs`; у шаблона, как у ASU, уровни свои:
«друзей» нет, а «скрыто» есть.
