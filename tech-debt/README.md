# Технический долг

Один файл — один долг, кратко о каждом. Закрыли долг — удаляете файл и его строку в таблице. Долги механизмов,
которых в шаблоне ещё нет, записаны вперёд: они приходят вместе с механизмом.

| Долг | Суть |
|--------|------|
| [Bootstrap поштучно через `@import`](sass-import.md) | Bootstrap собирается поштучно (`src/bootstrap.scss`, −121 КБ к initial) — держится на `@import` с заглушённым предупреждением Sass; Dart Sass 3.0 его сломает, Bootstrap 6 не ждём |
| [Вес бандла](bundle.md) | Бюджет initial — ошибка сборки на 427 КБ, замер 419.85 КБ (справка, markdown и перечитывание прав — ленивые; `resource()` и `ngTemplateOutlet` не берём — их код ложится в initial), запас ≈7.1 КБ, предупреждение на 422; замеры, история и что урезать дальше |
| [API — один экземпляр](single-instance.md) | Отметка сессии с правами (`SessionGuard`), лимиты паролей и сброса, повтор токена Telegram, ключ слияния и справка живут в памяти процесса; второй экземпляр — повод вынести их в Redis или базу |
| [Старт, память и образ API не настраивались](runtime-tuning.md) | Сознательно по умолчанию: Native AOT не делаем, TieredPGO и DATAS у .NET 10 включены сами, ReadyToRun требует RID в сборке и публикации `publish-api.yml`, chiseled ломает `HEALTHCHECK` на bash — когда заболит старт |
| [Схема базы — копией на каждый тест](test-schema-per-test.md) | База теста — копия шаблона со схемой (`CREATE DATABASE … TEMPLATE`) на общем Postgres в tmpfs; если копия станет заметной — пул баз и `TRUNCATE` |
| [Видимость полей профиля](profile-visibility.md) | Решено, пока не делаем: у каждого поля профиля уровень — скрыто (только для входа и восстановления), коллегам по общему workspace, всем. Карточка чужого профиля — по ним |
| [Знак и общий вид](visual-identity.md) | Значок вкладки — буква шаблона, тёмная тема по системе есть; знака в шапке и своей палитры нет — решение проекта из шаблона |
| [Админка в окне открытия — для всего интернета](admin-perimeter.md) | Списка адресов нет: админка открывается всем на 1–8 часов workflow `Admin Access`; в это окно держат только пароль продукта и лимит попыток. Взамен списка адресов — клиентские сертификаты на nginx (второго фактора не будет). Срок окна стерегут раннер и cron самой VM |
| [Телеметрия рассчитана на одну машину](telemetry-single-host.md) | Коллектор, Prometheus, Tempo и Grafana живут рядом с API в общей сети и находят друг друга по именам контейнеров; на несколько машин так не переехать |
| [Модель эмбеддингов мелкая](embeddings-model.md) | `multilingual-e5-small` на процессоре — из-за машины на 2 ядра; окно 512 токенов, сборка образа закреплена (`server-b11096`), новую — только после проверки на модели. Префиксы e5 включены, порог 0.83 замерен на маленькой выборке. Следующий шаг — bge-m3 |
| [Часовой пояс — только заголовком](assistant-timezone.md) | Ассистент берёт зону из `X-Time-Zone` запроса и помнит её в прогоне; поля в профиле нет. Клиент ставит заголовок только на `Send`, не перехватчиком. Поле в `Profile` — когда время начнёт вычислять сервер сам (напоминания, сводки) |
