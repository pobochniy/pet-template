# Ответ ассистента — без разметки

Лента чата (`src/app/assistant`) показывает ответ модели текстом как
есть, с переносами строк (`white-space: pre-wrap`). Модель отвечает по справке и любит
markdown: списки, `**жирный**`, ссылку на страницу из `page:` статьи — человек видит их
звёздочками и скобками.

В Lad ответ рисует `shared-markdown-preview` (свой разбор без библиотеки). В шаблоне его нет,
а тянуть в чат библиотеку markdown ради ядра, которое умеет только отвечать по справке, рано.

**Когда возвращаться** — первая жалоба на «звёздочки» или первый раздел проекта, чьи ответы
опираются на ссылки. Тогда:

- отрисовщик — ленивым чанком экрана чата (в initial ничего, `bundle.md`), без `innerHTML`
  с сырым текстом модели: ответ — недоверенный ввод (спец. assistant, 9);
- ссылки — только на свои маршруты (`routerLink`), чужие адреса — текстом;
- образец — Lad `shared/markdown-preview`.
