# Спецификации — что за продукт и как он себя ведёт

Поведение шаблона описано здесь; правила работы с кодом — в `agents.md` каждой подсистемы,
срезанные углы — в [`tech-debt/`](../tech-debt/README.md), что человек читает о сайте — в справке
[`help/`](../help/) (её пишут по спекам, `help.md`). Спеки описывают то, что есть в коде; чего ещё
нет — в разделах «Не реализовано» и «Открытые вопросы» самих спек. Меняете поведение — правьте спеку
в том же ПР.

| Документ | О чём |
|---|---|
| [`home.md`](home.md) | Главная и оболочка сайта: меню, шапка и переключатель пространства, плашка без пространства, строка ассистента, язык, маршруты верхнего уровня |
| [`authorization.md`](authorization.md) | Авторизация, права в контексте workspace и приглашения |
| [`accounts.md`](accounts.md) | Аккаунт и входы: логин, пароль и его восстановление, Telegram и VK, свежий вход, слияние и удаление |
| [`mail.md`](mail.md) | Письма: какие уходят, очередь и SMTP, записи DNS домена |
| [`search.md`](search.md) | Поиск: эмбеддер и Qdrant, `tsvector`, слияние RRF, индексация через очередь, реиндекс, изоляция пространств; рецепт подключения сущности |
| [`help.md`](help.md) | Справка: статьи `help/` без техники, линтер и сверка со спеками (`HelpCheck`), skill `help-sync`, поиск в памяти, публикация с выкаткой API |
| [`assistant.md`](assistant.md) | ИИ-ассистент: ход и растущий бюджет, согласие на план, гигиена цикла, тред и компакция, модели и размыкатель, API; рецепт инструментов раздела |
| [`admin.md`](admin.md) | Админка: отдельный сайт на поддомене, роли админов, разделы, приглашения |
| [`infrastructure.md`](infrastructure.md) | Репозиторий, проверки до коммита и до выкатки, workflow, сервер (`IaC/`), PostgreSQL |
